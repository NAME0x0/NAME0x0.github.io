# Task D1 — Film foundation + Chapter 0 (Ignition)

Context: The homepage (`app/page.tsx`, server component) is a complete 8-section editorial page. The film is a fixed WebGL canvas that mounts BEHIND that content for capable devices only. The editorial page IS the fallback — do not degrade it in any way. Deps available: three, @react-three/fiber@8, @react-three/drei@9, lenis, detect-gpu, framer-motion.

Storyboard (docs/BRIEF.md §3–4, v2): The Machine is a GPU being forged then awakened. D1 ships: the gate, the scroll/progress system, chapter analytics, and Chapter 0 — a bare silicon die in the void, edge-lit, "4 GB" engraved, camera pushing in as the user scrolls chapter 0's band.

## 1. Gate — components/film/FilmMount.tsx ("use client")
Mounted from `app/page.tsx` (server) as `<FilmMount />`. Inside:
- `next/dynamic` import of the canvas with `ssr: false`.
- Mount the canvas ONLY if all pass:
  - `!window.matchMedia("(prefers-reduced-motion: reduce)").matches`
  - WebGL2 context creation succeeds
  - `getGPUTier()` from detect-gpu: require `tier >= 2` and not `isMobile` with tier < 3 (i.e. mobile needs tier 3; desktop needs tier 2 — approximates the iPhone 13-class floor)
  - `navigator.connection?.saveData !== true`
- While deciding or when any check fails: render `null`. The page must be byte-identical in content either way.
- When the film mounts, set `document.body.dataset.film = "on"`; remove on unmount.

## 2. Film mode CSS — app/globals.css
When `body[data-film="on"]`:
- Sections `#ignition, #metal, #voice, #mind, #council, #blueprint, #light` lose their opaque background (transparent) so the canvas shows through; their inner content containers get a readability scrim: `background: radial-gradient(ellipse at left, rgba(0,0,0,0.72), transparent 70%)` or equivalent — text must keep WCAG AA over any canvas state.
- `#human` KEEPS its solid paper background (the film powers down behind it).
- The canvas wrapper: `position: fixed; inset: 0; z-index: 0; pointer-events: none;` and main content sits at `z-index: 1` (relative). Verify links/buttons stay clickable.

## 3. Scroll + progress — lib/film/progress.ts ("use client" consumers)
- Initialize Lenis smooth scroll ONLY when the film is mounted (gate passed). Destroy on unmount. Never initialize under reduced-motion (gate already prevents mount).
- A tiny subscription store (no new deps, no zustand): `createProgressStore()` holding `{ p: number, chapter: number, chapterLocal: number }` where `p` = overall scroll progress 0–1, `chapter` = current chapter index 0–7, `chapterLocal` = 0–1 within that chapter. Compute chapter bands by MEASURING the 8 section elements' offsetTop/height on mount + resize (ResizeObserver on body) — never hardcode fractions. Update on Lenis scroll event via rAF-throttle. React hook `useFilmProgress()` reads it without re-rendering per frame (subscribe in useFrame/refs, NOT setState per scroll).

## 4. Chapter analytics — components/site/ChapterTracker.tsx ("use client")
Separate from the film (must work when film is gated off): IntersectionObserver over the 8 section elements; first time each becomes ≥50% visible, fire `chapter_reached` with its index via `lib/analytics.ts` (event type already exists), once per page view. Mount in `app/page.tsx` unconditionally.

## 5. The canvas — components/film/FilmCanvas.tsx + scenes
R3F `<Canvas>`:
- `dpr={[1, 1.5]}` with drei `<PerformanceMonitor>` stepping down to 1 on sustained low FPS.
- `frameloop` set to `"never"` when `document.hidden` (visibilitychange listener) — otherwise `"always"`. (The canvas is fullscreen-fixed on the homepage, so no offscreen case in D1.)
- `gl={{ antialias: true, alpha: true, powerPreference: "high-performance" }}`, no postprocessing, no OrbitControls.
- Environment: use `RoomEnvironment` from `three/examples/jsm/environments/RoomEnvironment.js` through `PMREMGenerator` for PBR reflections. **HARD CONSTRAINT: zero network asset fetches** — the CSP allows only 'self'; drei `<Environment preset>` fetches from a CDN and is FORBIDDEN. Everything procedural.

### Chapter 0 scene — components/film/scenes/Die.tsx
A bare silicon die, photoreal-leaning through materials + light (not mesh complexity):
- **Die**: a low-height box (~2.2 × 2.2 × 0.12 world units) with `MeshPhysicalMaterial`: base color near-black `#101010`, `metalness 0.55`, `roughness 0.32`, `clearcoat 0.6`, `clearcoatRoughness 0.25`.
- **Circuit texture**: generate a canvas texture (1024², created client-side once): dark substrate, fine grid of thin lines + small pads/blocks in two tones (`#1C1A17` lines, sparse `#C4B5A0`-tinted pads at ~6% opacity) — used as roughnessMap and lightly as emissiveMap (emissive `#C4B5A0`, emissiveIntensity 0.05, so traces catch light subtly). Set `anisotropy` from renderer caps.
- **Engraving**: same canvas approach, a second texture region or decal-plane on top: text `4 GB` (Geist-mono-like: use `700 120px monospace`) + a small `NAME0x0` in a corner, rendered as slightly-lighter roughness so it reads as etched; NOT a glowing sticker.
- **Substrate shadow**: die floats over void; add a very soft contact shadow (drei `<ContactShadows>` opacity ~0.35, blur high) so it doesn't look pasted.
- **Lights**: key `DirectionalLight` color `#C4B5A0` intensity ~2.2 from upper-left; rim `PointLight` color `#D08C5A` intensity ~1.2 low-right behind; ambient near-zero (`0.06`). Void background: `null` (transparent canvas over page's black).
- **Idle motion**: die slowly rotates (y, ~0.05 rad/s) and floats (±0.03 sine) so the scene is alive pre-scroll.
- **Scroll choreography (chapter 0 band)**: camera starts at `z≈7, y≈2.4, x≈-1.2` looking at die; as `chapterLocal` 0→1, dolly to `z≈3.4, y≈1.1` with slight orbit (use damped lerp toward targets driven by `useFilmProgress()` inside `useFrame` — no React state). Past chapter 0 (chapters 1–7 for now): hold the final framing and slowly fade the whole scene's opacity toward 0.25 (placeholder until later chapters land) — implement fade via a uniform/material opacity on a fullscreen fade plane or group opacity handling, NOT by unmounting.

- 60fps target on a desktop tier-2 GPU; every per-frame path allocation-free (reuse vectors; no `new` in `useFrame`).
- `npx tsc --noEmit`, `npm run lint`, `npx next build` (font-mock allowed) must pass. First-load JS on `/` must stay < 180 kB gzip — the film bundle must be code-split behind the dynamic import; report the route's first-load JS from the build output.
