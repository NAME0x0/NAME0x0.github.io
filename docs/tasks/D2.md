## 2. Chapter 3 — Mind (AVA benchmarks as light)
When `chapter === 3` (grow in with `chapterLocal`, ease smoothstep):
- **Boot flash**: at the 2→3 boundary, briefly raise the die's circuit emissiveIntensity (0.18 → ~0.6 → settle 0.35) over ~0.6s of chapterLocal — the silicon wakes.
- **Benchmark columns**: three translucent light columns rise from the die's top face, arranged along its right edge (must not occlude the copy column on the left):
  - ARC-C 82.0% — `signal`, height proportional to 0.82
  - ARC-E 92.0% — `signal`, height proportional to 0.92 (tallest)
  - Llama 3.2 3B baseline 78.6% — `dim`, height 0.786, thinner
  Build each as a vertical box or cylinder with `MeshBasicMaterial` (`transparent`, `opacity ~0.55`, `blending: THREE.AdditiveBlending`, `depthWrite: false`) plus a brighter thin core. Heights animate 0→full with chapterLocal (staggered ~0.1 each). NO postprocessing bloom — additive layering + a soft radial-gradient canvas sprite at each column's base gives the glow.
- **Labels**: canvas-texture sprites (procedural, monospace text on transparent bg, e.g. "ARC-C 82.0"), one floating at each column's top, small, `dim` for baseline / near-`signal` tint for measured. No troika/drei `<Text>` (it fetches fonts — CSP forbids).
- **Rising motes**: ~400 points (single BufferGeometry, custom shader or PointsMaterial with the D1 glow-sprite technique) drifting slowly upward from the die surface while chapter ∈ [3,6], opacity tied to chapter presence. Allocation-free per frame; attributes created once.
