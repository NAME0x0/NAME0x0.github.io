## 1. Security headers — next.config.mjs `headers()`
Add an async `headers()` returning, for `/(.*)`:
- `Content-Security-Policy`: `default-src 'self'; script-src 'self' 'unsafe-inline' https://va.vercel-scripts.com; style-src 'self' 'unsafe-inline'; img-src 'self' data: https://avatars.githubusercontent.com; font-src 'self'; connect-src 'self' https://api.github.com https://va.vercel-scripts.com; frame-ancestors 'none'; base-uri 'self'; form-action 'self'; object-src 'none'; upgrade-insecure-requests` — NO `unsafe-eval` anywhere. (Note: `'unsafe-inline'` for script-src is a documented compromise: SSG pages cannot carry per-request nonces, and hashing Next's own inline RSC scripts is not maintainable. Leave a comment saying exactly this.)

- `X-Content-Type-Options: nosniff`
- `Referrer-Policy: strict-origin-when-cross-origin`
- `Permissions-Policy: camera=(), microphone=(), geolocation=(), interest-cohort=()`
- `X-Frame-Options: DENY`

## 3. CI — .github/workflows/ci.yml
On push to any branch + PRs to main. Node 20, npm ci (set env `GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}` only where needed). Jobs/steps:
1. **lint-typecheck**: `npm run lint`, `npx tsc --noEmit`.
2. **banned-vocab**: grep gate — fail if `sovereign|SYS\.INIT|secure enclave` (case-insensitive) matches in `app components lib content` (use `grep -riE` with explicit exit-code handling so no-match = success).
3. **secret-scan**: gitleaks official action (`gitleaks/gitleaks-action@v2`) scanning the repo.
4. **audit**: `npm audit --omit=dev --audit-level=high` — failing on high+ prod vulns.
5. **build**: `npm run build` (snapshot + verify-claims run via prebuild; they must pass on the warning path if no network/token — they already handle this).
6. **lighthouse**: after build, run Lighthouse CI (`treosh/lighthouse-ci-action@v12`) against `npx next start` serving `/` and `/work/ava`, with budgets: performance ≥ 0.85, accessibility ≥ 0.95, best-practices ≥ 0.95, seo ≥ 0.95 via `lighthouserc.json` assertions (categories, "error" level). Mobile emulation default.
Create `lighthouserc.json` at repo root.
