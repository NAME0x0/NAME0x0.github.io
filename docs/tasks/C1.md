# Task C1 — /writing MDX pipeline, RSS, per-route OG images

Context: continues B-phase. New deps installed and available: `next-mdx-remote`, `gray-matter`, `remark-gfm`. One real post already exists at `content/writing/triton-fla-bitsandbytes-windows.mdx` (frontmatter: title, description, date, tags[], sourceGist). Design language and components from B2 apply (void/ink/dim/bone/signal, mono overlines, 68ch prose column).

## 1. Content layer — lib/content/writing.ts
- Read all `content/writing/*.mdx` with `gray-matter`; zod-validate frontmatter: `{ title, description, date: YYYY-MM-DD string, tags: string[] (optional, default []), sourceGist: url (optional), updated: YYYY-MM-DD (optional) }`. Slug = filename.
- Export `getAllPosts()` (sorted by date desc) returning `{ slug, frontmatter, content, readingMinutes }` — readingMinutes = ceil(words/200).
- Build must fail on invalid frontmatter (zod throw is fine).

## 2. Routes
- `app/writing/page.tsx` (server): overline `// WRITING`, list of posts: title (link), date in mono, description, reading time. Metadata title "Writing". If future empty state ever occurs, render nothing weird — but there is always ≥1 post.
- `app/writing/[slug]/page.tsx` (server, SSG): `generateStaticParams` from posts; `generateMetadata` (title, description). Render with `next-mdx-remote/rsc` `MDXRemote`, `remarkPlugins: [remarkGfm]`, NO rehype-raw (raw HTML must not pass through). Style MDX output via a `components` map or a prose wrapper consistent with the site (headings font-display, code blocks font-mono with border-faint bg, links bone underline, tables styled like MetricsTable's aesthetic). Header block: h1 title, mono date + reading time, tags row; if `sourceGist` present, a line "Also published as a gist" linking it (external rel).
- Reading-progress event: `components/site/ReadProgress.tsx` ("use client"): IntersectionObserver on a sentinel div placed at 50% of the article (or scroll-percent listener), fires `writing_read_50pct` with slug ONCE per page view via lib/analytics. Mount it in the post page. No visual output.

## 3. RSS — app/writing/rss.xml/route.ts

XML-escape all text fields (&, <, >, ", '). Content-Type `application/rss+xml`.
- Add `<link rel="alternate" type="application/rss+xml" ...>` to the writing index page metadata (Next metadata `alternates.types`).

## 4. Sitemap
- Update `app/sitemap.ts`: add `/writing` and each post URL.
