# Analytics Funnel

The analytics funnel is intentionally small: land, see proof, open a case study, then choose CV or email.

| Event | Where It Fires | Funnel Question |
| --- | --- | --- |
| `chapter_reached` | Defined only; film scroll tracking lands later. | Which narrative chapters are reached once the canvas is live? |
| `case_study_opened` | Homepage case-study links, proof CTA, and work cards. | Did a visitor move from overview to proof? |
| `demo_clicked` | Homepage and case-study demo links. | Did a visitor inspect a live project? |
| `cv_downloaded` | Header CV link, human-section CV link, and CV PDF link. | Did a recruiter ask for the resume artifact? |
| `email_clicked` | Email CTAs and footer email. | Did a visitor start a conversation? |
| `github_clicked` | Header GitHub, footer GitHub, about GitHub, and human-section GitHub. | Did a technical visitor inspect source credibility? |
| `writing_read_50pct` | Defined only; writing route lands later. | Which writing pieces are read deeply enough to count? |
